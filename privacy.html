プライバシーポリシー / Privacy Policy

最終更新 / Last updated: 2026-10-26

1. このツールについて / About

このツールは、運営者本人が自分の YouTube チャンネルを管理するためだけに使います。運営者以外の利用者はいません。
This tool is used solely by its operator to manage the operator's own YouTube channels. There are no other users.

2. 取得する情報 / Data accessed

Google の OAuth で運営者本人が許可した範囲で、YouTube Data API・YouTube Analytics API・YouTube Reporting API を通じて、運営者自身のチャンネルの情報（動画の一覧と設定、再生数などの統計、視聴者の年齢・性別・国の集計値）を読み、運営者自身のチャンネルへ動画を投稿・更新します。個々の視聴者を特定できる情報は扱いません。
With the operator's own OAuth consent, the tool reads data about the operator's own channels (video lists and settings, view statistics, aggregated audience age/gender/country) and uploads or updates videos on those channels via the YouTube Data, Analytics and Reporting APIs. It does not handle information that identifies individual viewers.

3. 保存と共有 / Storage and sharing

取得したデータと認証トークンは、運営者のパソコンの中にだけ保存します。第三者への提供・販売・広告への利用はしません。
Data and OAuth tokens are stored only on the operator's own computer. They are never sold, shared with third parties, or used for advertising.

4. Google API サービスのユーザーデータに関するポリシー / Google API Services User Data Policy

Google API から受け取った情報の利用と他のアプリへの転送は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。
Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. 許可の取り消し / Revoking access

許可は Google アカウントのサードパーティ アクセス からいつでも取り消せます。
Access can be revoked at any time from your Google Account's third-party access page.
